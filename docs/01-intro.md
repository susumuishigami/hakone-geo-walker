# はじめに

% 骨子スケルトン（初期スコープ定義時点）。本文は今後加筆する。

## 問題設定

本研究の主題は、街道の「歩きやすさ」そのものの評価ではなく、**ある経路がなぜその場所に
決定され、選ばれ続けた（あるいは衰退した）のか**という、経路決定理由の評価である。

% 歩きやすさは経路決定の一要因にすぎない。歩きづらい道は踏みしめられず消えていく一方で、
% 現に選ばれ維持された道には、地形的不利を補ってなお選ばれるだけの理由がある。
% 本研究は箱根越えを事例に、その「決定理由」を地理データと史料から多面的に評価する。

## 動機

% 著者が箱根越えの各経路を実地に歩いた体感として、道そのものの歩きやすさ／歩きにくさは
% 距離・勾配・標高といった量だけでは説明しきれないと感じた。さらに、歩きやすさだけでは
% 「なぜこの道が選ばれたのか」を説明できないという、より根本的な問いに行き着いた。

% 俗説との対比（※ 専門家の説ではなく、現地案内や旅行系の解説に見られる素朴な理解。
% 出典は要確認・未検証）: 「箱根の道は古来の悪路を江戸期の土木技術で克服したもので、
% 現代の靴では歩きにくい石畳も当時の草鞋では歩きやすかった」とする理解がある。しかしこれは
% ぬかるみにくい尾根筋の湯坂路の存在を説明できず、石畳が当時の歩行者にとっても容易だったと
% する点にも無理がある。本研究はこの素朴な理解を出発点の対比とし、経路決定をより妥当な
% 枠組みで捉え直す。

## 着眼点：決定要因の束

経路決定を、単一の「歩きやすさ」ではなく、相互に競合する複数の要因の束として捉える。

- **歩行容易性**：歩いて越える際の身体的・心理的な容易さ（距離・勾配・標高に加え、
  道の周囲との標高差＝谷筋度、路面の湿潤性を考慮する）。
- **道の作りやすさ・直しやすさ**：道を新設・維持・復旧する難易。
  % 仮説: 尾根筋の道は作りやすく壊れにくい。谷筋の道は流水・崩落で壊れやすく直しづらい。
  % 傍証（今回のテーマ外だが示唆的・要確認）: 箱根西坂では、ゴルフ場開発で再発見された
  % 『平安鎌倉古道』が実際に歩きやすい一方、東海道（箱根八里）西坂では甘酒茶屋付近で崩落が
  % 発生し、通行再開までに長期間を要している（※時期・規模は要確認）。現代の土木技術でも
  % 谷筋寄りの道は「壊れやすく直しづらい」可能性。東坂の須雲川ルート（箱根八里）と湯坂路の
  % 対比にも同様の構図を予想する。
- **経済的優位**：沿道集落・耕地・物資輸送・宿駅機能などの経済的便益。
  % 仮説: 谷筋の道は歩きづらく壊れやすいが、経済的便益が高い。
  % 須雲川沿いには畑宿があり、『東海道中膝栗毛』には馬を飼う描写がある（※膝栗毛は一次資料
  % ではない。ただし馬を養える土地条件の存在を示唆）。現在も谷筋の旧道（須雲川沿いの車道）や
  % 三島側の国道一号線沿いは集落・畑が続く。室町期には既に畑宿の存在が確認され（※要出典）、
  % 石畳の箱根八里整備以前からこの谷筋を往来する人がいたことが示唆される。
- **政治的思惑**：為政者の意図・制度（関所・宿駅制・参勤交代等）。
  % 政治的思惑は定性的にしか評価できない。しかし「地形的に不利な道が現に選ばれた」という
  % 事実があれば、その不利を打ち消すだけの政治経済的理由が働いたと逆算できる。すなわち
  % 定性的要因を、地形的不利の定量値として逆説的に下限評価できる、という発想。

## 研究の問い（RQ）

> **RQ1**: 箱根越え各経路の「歩行容易性」「作りやすさ・直しやすさ」を、実地歩行ログと
> 地理データからどの程度定量化できるか。
>
> **RQ2**: それらの地形的要因だけで経路の選択・盛衰をどこまで説明できるか。説明しきれない
> 残差を、経済的・政治的要因としてどう位置づけられるか。

## 仮説と反証条件

- **H1（地形的要因の多面性）**: 谷筋度・湿潤性・崩れやすさを含めて評価すると、経路間の
  優劣は単純な勾配・距離評価とは異なる像を結ぶ（例: 湯坂路は歩く道として特段に不利でない）。
- **H2（経済的優位の競合）**: 谷筋の道（須雲川＝畑宿系）は地形的には不利でも経済的便益が高く、
  その便益が地形的不利と競合して経路選択に効いている。
- **H3（政治的要因の逆説的定量化）**: 地形的・経済的要因で説明しきれない経路選択の残差は、
  政治的思惑の寄与として下限評価できる。
- **反証条件**: もし地形的要因（拡張指標を含む）だけで経路の選択・盛衰が一貫して説明でき、
  残差が無視できるなら、経済的・政治的要因を主要因とする見立て（H2・H3）は支持されない。
- 本稿は因果の断定ではなく、各要因の説明力の評価に射程を限定する。

## 本稿の貢献と構成

% (1) 経路決定を「決定要因の束」として捉える枠組みの提示（歩行容易性・作りやすさ／直しやすさ・
%    経済的優位・政治的思惑）。
% (2) 運動生理学に依らず、実地歩行ログ・地理情報・歴史文献から地形的要因を定量化し、
%    箱根越え各経路を比較。
% (3) 説明しきれない残差を経済的・政治的文脈に位置づけ、定性的要因を逆説的に下限評価する。
% 以降の構成: 2章 背景・先行研究、3章 方法、4章 結果、5章 考察、6章 結論、7章 限界と今後。
