# 結論

% 骨子スケルトン。本文は今後加筆する。断定の強さは「説明力比較」の射程に調整する。

% 想定する結論（初期スコープ定義時点の暫定）:
% 1. 経路決定は単一の歩行容易性ではなく、歩行容易性・作りやすさ／直しやすさ・経済的優位・
%    政治的思惑が競合する「決定要因の束」として捉えるべきである。
% 2. 谷筋度・湿潤性・崩れやすさを含めて評価すると、湯坂路は歩く道として箱根八里に対して
%    決して不利ではない。
% 3. 谷筋の道（須雲川＝畑宿系）は地形的に不利でも経済的便益が高く、その競合が経路選択に効く。
% 4. 地形的・経済的要因で説明しきれない残差は、政治的思惑の寄与として下限評価できる。
%    （※ 本研究の射程内では各要因の説明力比較にとどめ、最終原因の断定は限定的に述べる。）
