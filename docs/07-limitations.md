# 限界と今後の課題

% 骨子スケルトン。本文は今後加筆する。

## 本研究の限界

% - 季節・天候・気温による歩行ログのばらつき（統制の限界）。
% - 単独被験者ゆえの個人差・反復回数の少なさ。
% - 江戸期の路面状態の復元に伴う不確実性（史料の解釈幅）。
% - DEM 解像度・座標系に起因する GIS 指標の誤差。
% - 係数の逆算は限られた実測点へのフィッティングであり、外挿には注意。
% - 政治的思惑の「逆説的定量化」は残差からの下限評価であり、他要因の見落としがあれば過大評価となる。
% - 経済的優位の評価は定性的記述に依存し、史料（特に二次資料）の解釈幅が大きい。

## 今後の課題

% - 反復踏査・複数被験者による統計的頑健性の向上。
% - 他の歴史的街道への手法の一般化（西坂の平安鎌倉古道など）。
% - 湿潤 proxy（TWI 等）の現地計測による検証。
% - 作りやすさ・直しやすさの定量化精緻化（崩落履歴・普請記録の体系的収集）。
% - 経済的要因の定量化（沿道集落人口・耕地面積等の地理データ化）。
