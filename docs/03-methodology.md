## 用語の定義

経路決定要因
: ある経路が選択・維持・衰退する理由となる要素の総称。本研究では地形的要因（歩行容易性・
  作りやすさ／直しやすさ）と非地形的要因（経済的優位・政治的思惑）に大別する。

歩行容易性 (walkability)
: ある経路区間を歩いて越える際の身体的・心理的な容易さ。本研究では**客観指標**（区間速度・
  移動時間、停止回数、累積上昇、勾配分布、路面状態）と**主観指標**（RPE 等のきつさ主観、
  危険感、足への負担感）の双方で操作的に定義する。

作りやすさ・直しやすさ (buildability / maintainability)
: 道を新設・維持・復旧する難易。崩落・流水・湿潤による劣化のしやすさと、その復旧の困難さで
  捉える。谷筋度・湿潤 proxy・崩落履歴を手がかりに評価する。

谷筋度 / 周囲標高差
: 道上の各地点が周囲地形に対してどれだけ低い（谷）か高い（尾根）かの度合い。各地点の
  周囲標高差を経路に沿って積分した値を用いる。歩行容易性と作りやすさ・直しやすさの双方に効く。

湿潤 proxy
: 路面の湿りやすさ・流失しやすさの代替指標。TWI（地形湿潤指数）や最寄り水系までの距離で
  近似する。

経済的優位
: 沿道集落・耕地・物資輸送・宿駅機能などの経済的便益。沿道の集落・耕地分布や史料の記述で
  定性的に捉える。

## データと方法の対応

% RQ と要因に方法を対応づける:
% - 歩行容易性 → 実地歩行ログ + GIS 地形指標
% - 作りやすさ・直しやすさ → GIS（谷筋度・湿潤 proxy）+ 崩落/普請の史料・現地観察
% - 経済的優位 → 沿道集落・耕地分布 + 史料（畑宿・馬等）
% - 政治的思惑 → 制度史（関所・宿駅・参勤交代）+ 残差からの逆算

## 実地歩行ログの設計

% 統制条件: 2025年10月の湯坂路踏査に近い気温帯で箱根八里を再踏査。荷重・靴・休憩戦略を統制。
% 区間定義: 信号待ち・撮影・休憩を除外した「歩行セグメント」を切り出して比較。
% 取得指標: GPS ログ（速度・時刻・標高）、停止、可能なら心拍、主観 RPE。

## GIS 地形指標

% 既存指標: 勾配、距離、累積上昇。
% 追加指標（本研究の新規性）:
%   - 周囲標高差の積分（谷筋度）
%   - TPI（Topographic Position Index, 尾根/谷判定）
%   - TWI（Topographic Wetness Index, 湿潤 proxy）
%   - 距離 to 水系（最寄り水系までの距離）
% これらは歩行容易性と作りやすさ・直しやすさの双方の説明変数となる。
% ※ DEM の出典・解像度・座標系（EPSG）を明示する。

## 説明力の評価と残差の解釈

% 地形的要因（歩行容易性・作りやすさ／直しやすさ）を合成したスコアを定義し、
% 各経路の選択・盛衰をどこまで説明できるかを評価する。係数は実地ログから逆算。
% 地形的・経済的要因で説明しきれない残差を、政治的思惑の寄与の下限として位置づける
% （定性的要因の逆説的定量化）。
% 再現性: 乱数シード固定、入力データのパス・バージョン明示、出力先明示。

## 史料・現地観察の扱い

% 路面状態（石畳の流失）、維持管理（崩落と復旧遅延）、沿道集落・耕地、制度に関する
% 史料・観察を、定量結果の解釈材料として整理する。歴史的事実は確定情報のみ記述し、
% 未確認は注釈を付す（『東海道中膝栗毛』は一次資料ではない点に留意）。
